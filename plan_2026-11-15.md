## 2. Gaps in existing code that block frozen tests

1. `run_rq1` switches true data off above 2 x eps_ref, but D3 (v1.5) needs the 8-64 calibration points, a debiased D-hat and a bootstrap CI at **16 x**. Add them.
2. D4 needs rms(a), sd(d) and CV(d) per cell, and D1 needs per-point correlations. Save **per-point arrays** (signals, A, D, E, and per horizon window for G1) as an npz per cell, so Model A inputs and any metric change need no rerun.
3. The extra eps levels (4, 8, 16 x) must run at n_nom = 512 only, as v1.5 says.
4. No statistics code exists: Holm correction, BCa bootstrap, exact sign test, equivalence test (TOST), four-parameter logistic fit with convergence rule.
5. No Family A runner, no Family F runner, no pilot runner, no phase guard. The phase guard: the pilot accepts only seeds 0, 101, 102; the main run accepts only seeds 1-10 and **refuses to start unless the `pred-v1` tag exists**.
6. Model seeds collide: `Ensemble(base_seed=seed)` uses member seeds `base_seed * 100 + m`, and the discrepancy ensembles use `seed * 10000 + n`, so seed 8's nominal members equal seed 0's discrepancy members at n = 8. Derive model seeds from `stream_seed(seed, purpose, index)` too.
7. `conformal_quantile` at n_cal = 8 uses the sample maximum, so the guarantee there is 8/9 = 0.889, not 0.90. Log this in v1.6 clarifications.
8. Arm 8's pool denominator cost 250 s per run in the smoke test. Share the cache across cells of the same seed.
9. Runners must use the same pattern as `run_rq1`: resumable JSONL, stderr to a log file, worker count set from free memory.
10. For the PDE track, `scale_inputs`, `residual_score` and `rq1_cell` are pendulum-specific; a small System abstraction (box, simulator, residual, nominal) is needed first.

## 8. The strict R1 (checked on three development seeds, awaiting approval)

Narrowing the bracketing band is the wrong way to be stricter: with the true family removed from the dictionary, the 5th to 95th percentile band missed the actual value for ensemble sigma on S1 in 3 of 3 seeds at 1 x and 4 x, and the min-max range missed it in 2 of 3 seeds at 16 x. v1.6 section 5 now has instead: **R1** (bracket, full dictionary), **R1s** (the true-family term's predicted correlation is within 0.20 of the actual, at 4 x and 16 x; largest development gap 0.13), **R1c** (true-family-removed bracket, descriptive, expected to fail on S1), and **R3a and R3b** promoted from exploratory to secondary tests. The result behind R3: from 8 real trajectories the term picked from the dictionary has a Spearman correlation of 1.00 (S1) and 0.99 (S2) with the true discrepancy norm, against 0.65 to 0.72 and about -0.1 for ensemble sigma; with the true family removed it is still +0.84 and +0.62. Caveats are written into v1.6 (the dictionary was written knowing the truth; collinear terms; three seeds). Tolerance, thresholds and test list are the author's call.
